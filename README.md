## ⭐ Featured Project

## 🎓 KLAP – Kids Learning & Assessment Program

**KLAP** is a full-stack web application designed to provide an interactive and structured learning environment for children.
It integrates learning content, online assessments, performance tracking, and a reward system to enhance engagement and motivation.

---

## ⭐ Key Features

### 👨‍👩‍👧 User Module (Student/Parent)

* User registration and secure login
* Browse learning content by categories
* Interactive learning with text-to-speech support
* Online MCQ-based tests with timer
* Auto-save answers during tests
* Restricted navigation (auto-submit on violation)
* Instant results with score and feedback
* Earn Supercoins based on performance
* Redeem rewards like certificates and practice sets

---

### 🛠️ Admin Module

* Add / Update / Delete categories
* Manage learning content
* Add / Edit / Delete questions
* Manage users and monitor performance
* Track test results and analytics
* Manage Supercoins and reward items
* Generate system reports

---

## ⚙️ Core Functionalities

* Role-based access (User & Admin)
